# 2026-06-20 架构优化进度

## A153：建立 RepoGuard 审查质量评测集第一版基础设施

状态：已完成

本次新增 10 个可重复运行的离线 PR 评测 case，覆盖安全、稳定性、干净 PR、数据库迁移、消息队列和外部调用治理。评测不访问真实 GitHub、LLM 或生产基础设施，固定输入包括 PR diff 和可选的模型 JSON 响应。

评测链路复用生产代码中的：

- `RuleBasedPullRequestReviewer`
- `PullRequestDiffChunker`
- `LlmReviewResultParser`
- `LlmRuleReviewMerger`

每个 case 对风险等级、发现数量、规则编号、发现来源和 diff 分块原因进行断言；数据集同时断言 case 数量和核心类别覆盖，便于后续增量扩充并防止评测样本被意外删除。

验证命令：

```bash
cd repoguard-backend
mvn -Dtest=ReviewQualityEvaluationTest,RuleBasedPullRequestReviewerTest,PullRequestDiffChunkerTest,LlmReviewResultParserTest,LlmRuleReviewMergerTest test
mvn test
```

- 聚焦测试：25 个测试通过，0 失败、0 错误、0 跳过。
- 后端全量测试：525 个测试通过，0 失败、0 错误、0 跳过。
