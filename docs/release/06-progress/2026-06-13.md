### 2026-06-13 P3-02A LLM 审查质量闭环基础数据沉淀

已完成：
- 新增 `V21__review_task_llm_quality.sql`，在 `review_task` 上沉淀 LLM provider、模型名、LLM 耗时、解析状态、兜底原因和脱敏 prompt 摘要。
- `ReviewResult` 扩展质量元数据，LLM 审查成功时记录 `parsed`，规则兜底时记录 `fallback` 和兜底原因。
